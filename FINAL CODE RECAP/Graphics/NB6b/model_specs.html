Regression Specifications

54-country sample  ·  1995–2019  ·  OLS with clustered standard errors by country  ·  All interaction terms are mean-centred before multiplication.

Pooled OLS models

M1 Kitchen-sink OLS  ·  Dep. var: log(ECI)
$$\log(\text{ECI}_{it}) = \alpha + \boldsymbol{\beta}'\mathbf{X}_{it} + \varepsilon_{it}$$

Purpose: unrestricted benchmark with the full variable set (~40 regressors) covering resource dependence, macroeconomic conditions, governance, human development, and finance. Clustered SE by cluster group.
DV: log ECI SE: clustered by cluster group ~40 regressors

M2 AR baseline  ·  Dep. var: ECI
$$\text{ECI}_{it} = \alpha + \rho\,\text{ECI}_{i,t-1} + \varepsilon_{it}$$

Purpose: pure autoregressive benchmark. Establishes how much of ECI variation is explained by inertia alone, before adding substantive regressors. Any model that fails to substantially exceed this R² offers little explanatory power beyond persistence.
DV: ECI 1 regressor

3a Parsimonious — no lag  ·  Dep. var: ECI
$$\text{ECI}_{it} = \alpha + \beta_1 \log(\text{HCI}_{it}) + \beta_2 \log(\text{GFCF}_{it}) + \beta_3 \text{PolStab}_{it} + \beta_4 \text{RoL}_{it} + \beta_5 \log(\text{NRProd}_{it}) + \beta_6 \text{Trade}_{it} + \gamma_1 \widetilde{\text{HCI}}_{it} \times \widetilde{\text{NRProd}}_{it} + \gamma_2 \widetilde{\text{GFCF}}_{it} \times \widetilde{\text{NRProd}}_{it} + \varepsilon_{it}$$

Purpose: parsimonious specification with the core theoretical variables. Interaction terms test whether the effect of human and physical capital on complexity is moderated by natural resource dependence (resource-curse heterogeneity). No lagged ECI — estimates the level association, not the dynamic adjustment.
DV: ECI 8 regressors no ECI lag

3b Parsimonious + ECI(t−1)  ·  Dep. var: ECI
$$\text{ECI}_{it} = \alpha + \rho\,\text{ECI}_{i,t-1} + \beta_1 \log(\text{HCI}_{it}) + \beta_2 \log(\text{GFCF}_{it}) + \beta_3 \text{PolStab}_{it} + \beta_4 \text{RoL}_{it} + \beta_5 \log(\text{NRProd}_{it}) + \beta_6 \text{Trade}_{it} + \gamma_1 \widetilde{\text{HCI}}_{it} \times \widetilde{\text{NRProd}}_{it} + \gamma_2 \widetilde{\text{GFCF}}_{it} \times \widetilde{\text{NRProd}}_{it} + \varepsilon_{it}$$

Purpose: adds ECI(t−1) to 3a, controlling for persistence. Coefficients now measure the effect of each regressor conditional on last year's complexity level — i.e. what drives improvement or deterioration relative to the country's own trajectory. $\hat{\rho}$ close to 1 confirms high ECI persistence.
DV: ECI 9 regressors main preferred spec

3c All vars lagged  ·  Dep. var: ECI
$$\text{ECI}_{it} = \alpha + \rho\,\text{ECI}_{i,t-1} + \beta_1 \log(\text{HCI}_{i,t-1}) + \beta_2 \log(\text{GFCF}_{i,t-1}) + \beta_3 \text{PolStab}_{i,t-1} + \beta_4 \text{RoL}_{i,t-1} + \beta_5 \log(\text{NRProd}_{i,t-1}) + \beta_6 \text{Trade}_{i,t-1} + \gamma_1 \widetilde{\text{HCI}}_{i,t-1} \times \widetilde{\text{NRProd}}_{i,t-1} + \gamma_2 \widetilde{\text{GFCF}}_{i,t-1} \times \widetilde{\text{NRProd}}_{i,t-1} + \varepsilon_{it}$$

Purpose: lagging all regressors by one period reduces simultaneity bias — today's ECI cannot cause last year's HCI or governance. Also mitigates reverse causality. Compares to 3b to check whether contemporaneous vs lagged regressors give materially different estimates.
DV: ECI 9 regressors, all at t−1 simultaneity-robust

3d Extended controls  ·  Dep. var: ECI
$$\text{ECI}_{it} = \alpha + \rho\,\text{ECI}_{i,t-1} + \boldsymbol{\beta}'\mathbf{X}_{it} + \delta_1 \mathbf{1}[\text{Hydro}_{it}] + \delta_2 \mathbf{1}[\text{SubsoilMet}_{it}] + \delta_3 \mathbf{1}[\text{PrecMet}_{it}] + \delta_4 \text{Elec}_{it} + \varepsilon_{it}$$

Purpose: augments 3b with resource-type dominance dummies and electricity access, testing whether the type of resource dependence matters beyond the production level, and whether infrastructure access is an independent channel. Note: high multicollinearity in pooled OLS (max VIF = 49) — FE-3d is the preferred version of this spec.
DV: ECI 13 regressors use FE version

3e First differences (error-correction)  ·  Dep. var: ΔECI
$$\Delta\text{ECI}_{it} = \alpha + \delta\,\text{ECI}_{i,t-1} + \beta_1 \Delta\log(\text{HCI}_{it}) + \beta_2 \Delta\log(\text{GFCF}_{it}) + \beta_3 \Delta\text{PolStab}_{it} + \beta_4 \Delta\text{RoL}_{it} + \beta_5 \Delta\log(\text{NRProd}_{it}) + \beta_6 \Delta\text{Trade}_{it} + \beta_7 \Delta\text{Elec}_{it} + \gamma_1 \Delta(\widetilde{\text{HCI}} \times \widetilde{\text{NRProd}})_{it} + \gamma_2 \Delta(\widetilde{\text{GFCF}} \times \widetilde{\text{NRProd}})_{it} + \varepsilon_{it}$$

Purpose: proper first-difference specification — both sides are differenced. Time-invariant variables (dominance dummies) drop out by construction. ECI(t−1) is retained as an error-correction term: a negative $\hat{\delta}$ implies that countries farther above their long-run ECI path grow more slowly, consistent with mean-reversion. Coefficients measure how year-on-year changes in regressors predict year-on-year changes in complexity — a stricter and more causally interpretable test than levels.
DV: ΔECI 10 regressors, all first-differenced error-correction term

Country FE models (FE-3a to FE-3d)

FE-3a / FE-3b / FE-3c / FE-3d Within-group estimator  ·  Dep. var: ECI
$$\text{ECI}_{it} = \mu_i + \boldsymbol{\beta}'\mathbf{X}_{it} + \varepsilon_{it}$$
$$\Longleftrightarrow \quad \underbrace{(\text{ECI}_{it} - \overline{\text{ECI}}_i)}_{\text{within-country deviation}} = \boldsymbol{\beta}' \underbrace{(\mathbf{X}_{it} - \overline{\mathbf{X}}_i)}_{\text{within-country deviation}} + (\varepsilon_{it} - \bar{\varepsilon}_i)$$

Each FE model uses the same regressor set as its pooled counterpart (3a–3d) but absorbs country-level intercepts $\mu_i$ via within-group demeaning. The variable set $\mathbf{X}_{it}$ corresponds to the respective pooled specification.

Implementation: for each variable $v_{it}$, subtract the country time-mean $\bar{v}_i$ and add back the grand mean, then run OLS with a constant. This is the Frisch–Waugh–Lovell within-estimator, numerically identical to including $N-1$ country dummies.

Pooled OLS vs Country FE — key differences

Dimension Pooled OLS Country FE (within-estimator)
Variation used Both between-country (cross-sectional) and within-country (over time) variation. Only within-country, over-time variation. Cross-sectional differences across countries are removed.
Unobserved heterogeneity Assumes no country-specific unobservables correlated with regressors (strict exogeneity). Violation → omitted variable bias. Absorbs all time-invariant country characteristics (geography, institutions, culture) whether observed or not. Robust to this class of omitted variables.
Multicollinearity (VIF) High: HCI and GFCF are both development-level proxies correlated in the cross-section. Max VIF = 28–49 across specs. Resolved: within-country variation in HCI and GFCF is nearly orthogonal. Max VIF = 1.7–1.9 across all specs.
Time-invariant variables Identified: variables like dominance dummies or Landlocked have non-zero coefficients. Absorbed: variables with zero within-country variance (e.g. Landlocked) are collinear with the fixed effects and drop out. Dominance dummies survive because they do vary over time.
What the R² measures Share of total ECI variation (across countries and years) explained. Inflated by between-country differences in ECI levels. Within-R²: share of within-country, year-to-year ECI variation explained. More demanding and more meaningful for causal inference.
R² in practice 0.36 – 0.79 depending on spec. 0.09 – 0.29. Lower because it ignores the easy between-country signal — not a sign of worse fit.
Causal interpretation Estimates the association: "countries with higher HCI tend to have higher ECI." Confounded by omitted country-level factors. Estimates the within-country effect: "when a country's HCI rises above its own historical average, does ECI follow?" Cleaner causal interpretation.
Assumption required No omitted variable correlated with regressors (strong). No time-varying omitted variable correlated with regressors (weaker). Fixed country characteristics are controlled for by construction.
Preferred for this study M1, M2 as benchmarks. 3a–3e as robustness checks. FE-3b / FE-3d as main specifications — resolves multicollinearity, controls for unobserved country heterogeneity, and gives within-country causal estimates.

Variable notation

$\text{ECI}_{it}$ Economic Complexity Index, country $i$, year $t$
$\log(\text{HCI}_{it})$ log(1 + Human Capital Index)
$\log(\text{GFCF}_{it})$ log(1 + Gross Fixed Capital Formation, % GDP)
$\text{PolStab}_{it}$ Political Stability estimate (WGI)
$\text{RoL}_{it}$ Rule of Law index (WGI)
$\log(\text{NRProd}_{it})$ log(1 + NR production value per capita)
$\text{Trade}_{it}$ Trade openness (% of GDP)
$\text{Elec}_{it}$ Access to electricity (% of population)
$\widetilde{v}_{it}$ Mean-centred version of variable $v$: $v_{it} - \bar{v}$
$\mathbf{1}[\cdot]$ Indicator dummy (1 if resource type is dominant)
$\mu_i$ Country fixed effect (absorbed by within-group demeaning)
$\Delta v_{it}$ First difference: $v_{it} - v_{i,t-1}$
$\overline{v}_i$ Country time-mean: $T^{-1}\sum_t v_{it}$
$\varepsilon_{it}$ Error term, clustered by country
